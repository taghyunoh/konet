## 3. 배포 절차 — ✅이번 건은 끝났다 (다음 배포 때 쓰는 차례)

```
1) DDL : 이번 건은 없음
2) 9071  mvn compile  →  톰캣 재기동
3) 9072  mvn compile  →  톰캣 재기동
4) 포트·기동시각·로그 확인 (아래)
5) 눈 확인 3가지 (아래 §4)
```

⚠★**재기동 뒤 포트를 확인할 것** — 이 PC 에서 여러 번 겪었다.
옛 JVM 이 포트를 쥐고 있으면 새 톰캣이 `BindException` 으로 조용히 죽고, **자바는 새것 · 매퍼 XML 은 옛것**인 상태가 된다(컨텍스트가 `reloadable=true` 라 자바만 재로드된다).

```bash
powershell -c "foreach($p in 9013,9071,9014,9072){ $c=Get-NetTCPConnection -LocalPort $p -State Listen; if($c){ $r=Get-Process -Id $c[0].OwningProcess; '{0} PID {1} 기동 {2}' -f $p,$r.Id,$r.StartTime } else { '{0} 안 열림' -f $p } }"
```

- **종료 포트 9013 도 함께 본다** — 9013 만 잡은 javaw 가 살아 있으면 새 톰캣이 기동 직후 스스로 꺼진다.
- `catalina.<날짜>.log` 에 BindException 이 없는지 · PID 시작 시각이 방금인지 확인.
- 옛 JVM 은 `taskkill /PID <pid> /F` 로 내리고 다시 Start.

## 6. 되풀이된 함정 (여기서 실제로 당한 것만)

| 함정 | 규칙 |
|---|---|
| ★**「확인했음」만으로 완료로 적지 말 것** | 자료가 남는 기능은 `SELECT` 한 줄로 그 표를 세어 보고 적는다. 매퍼·화면이 멀쩡해도 저장이 0건이면 아무 흔적이 없다(창고 2단계가 그랬다) |
| 매퍼 XML 의 `<` | `<`·`<>`·`<=` 는 CDATA 나 `&lt;`. **주석 안에도** 적용된다 — 주석 하나로 XML 파싱이 통째로 깨진 적 있다 |
| `sed -i` · `perl -0pi` | **금지.** CRLF 가 LF 로 바뀌어 파일 전체가 변경된 것처럼 된다. CSS 한 줄을 고칠 때도 쓰지 말 것 |
| 이 PC 의 `python` | Windows 스토어 스텁이라 **아무 것도 안 하고 exit 0**. 스크립트는 **node 또는 perl** |
| `logistics_demo2.jsp` | `_jspService` **65,535바이트 한계**. 새 함수는 `js/winct/logi-oh.js` 에 넣고 JSP 는 기존 줄만 고친다 |
| curl 로 엔드포인트 찌르기 | `CompCdMybatisInterceptor` 가 세션 없는 요청에 `compCd=''` 를 넣어 **빈 목록**이 온다. 씨앗이 안 들어간 것으로 오해하지 말 것 — 표 확인은 사용자 SELECT 로 |
| MyBatis `<if test>` 한 글자 비교 | `useOnly == 'Y'` 는 char 로 읽혀 `NumberFormatException`. `== 'Y'.toString()` 을 쓸 것 |
| 두 앱 | 자바·SQL·화면을 고치면 **두 곳 다**. 한 번에 21문이 벌어져 있었다 |

## 7. 검증하는 법 (이 프로젝트에서 쓰는 방식)

로컬에 띄우지 않고도 대부분 걸러진다.

| 무엇 | 어떻게 |
|---|---|
| 자바 | `javac`(프로젝트 lib 116개 classpath) |
| 매퍼 | XML 파서로 정형성 + 구문 수·id 중복 + **MyBatis 로 실제 파싱**(`<include>` 가 풀리는지) |
| 화면 | JSP 인라인 JS 문법 · `node --check` |
| 셈·판정 | ★**실제 함수를 파일에서 정규식으로 떼어 node 로 돌린다** — 이번 구간 시뮬 = `sim_p2f.js`(16) · `sim_zodd.js`(14) · `sim_over.js`(12). 스크래치패드에 있다 |
| 자료 | `docs/tools/dbread/DbRead.java` — **SELECT 전용** 읽기 전용 조회기. 운영DB 이므로 무거운 조회는 피한다 |

★**임계값·규칙은 추측하지 말고 운영 자료로 정한다.** 이상 배지의 90%·10%·5일은 전부 실측에서 나왔고, 그 덕에 「날마다 0~2건」이라는 발화율을 미리 알고 냈다.

## 8. 비밀번호·설정 (저장소에 없다)

`<톰캣>\conf\` 안 파일 두 개 — git 밖이고 WAR 재배포에도 안 지워진다. **PC·서버마다 한 번씩** 만든다.

- `konet-db.properties` = `konet.db.password=…` ⚠**없으면 앱이 기동하지 못한다.** 운영에 새 WAR 를 올리기 **전에** 만들 것
- `konet-mail.properties` = `mail.smtp.password=…`

실행옵션 `-Dkonet.db.password=` / `-Dmail.smtp.password=` 가 파일보다 **먼저** 쓰인다 — 운영에 옛 실행옵션이 걸려 있으면 새 WAR 의 올바른 비밀번호가 조용히 무시된다(한 번 반나절을 썼다).
