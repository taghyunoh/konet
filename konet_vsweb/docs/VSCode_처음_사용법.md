# VS Code 처음 사용법 (konet_vsweb)

VS Code 를 처음 접하는 사람을 위한 최소 안내. 이클립스와 비교해 정리했다.
자세한 구축·설정 내용은 [VSCode_개발환경_가이드.md](VSCode_개발환경_가이드.md) 참고.

---

## 1. 좌측 세로 아이콘 줄 (활동 표시줄)

위에서부터 5개만 알면 된다.

| 아이콘 | 이름 | 이클립스로 치면 |
|---|---|---|
| 📄 문서 모양 | **탐색기** | Project Explorer |
| 🔍 돋보기 | **검색** | Ctrl+H 파일 검색 |
| ⑂ 가지 모양 | **소스 제어** | Git 퍼스펙티브 |
| ▷ 삼각형+벌레 | 실행/디버그 | Debug |
| ⊞ 네모 4개 | 확장 | Marketplace |

---

## 2. 탐색기 맨 아래 3개 패널

탐색기를 누르면 파일 목록 아래에 접혀 있다. 클릭하면 펼쳐진다.

- **MAVEN** → `konet_web` → Favorites → ▶ 누르면 **WAR 빌드**
- **SERVERS** → `konet_vsweb` 우클릭 → **Start / Stop / Restart** (이클립스 Servers 뷰와 동일)
- JAVA PROJECTS → 신경 쓰지 않아도 됨

---

## 3. 하루 작업 흐름

```
① 시작 전:  소스 제어 → ⋯ → Pull        (남이 바꾼 것 받기)
② 코딩:     파일 수정 → Ctrl+S 저장
③ 확인:     SERVERS에서 Start → localhost:9071
④ 끝나고:   소스 제어에 메시지 입력 → 커밋 → Sync Changes
```

- **JSP만 고쳤으면** 저장 후 브라우저 새로고침이면 끝 (서버 재시작 불필요)
- **`.java` 나 SQL XML 을 고쳤으면** → WAR 재빌드 + 톰캣 재시작 필요

---

## 4. 단축키 4개만

| 키 | 기능 |
|---|---|
| `Ctrl+S` | 저장 (이게 없으면 서버에 반영 안 됨) |
| `Ctrl+P` | 파일 빠른 열기 — 파일명 일부만 쳐도 찾아줌. **제일 많이 쓴다** |
| `Ctrl+Shift+P` | 모든 명령 검색 (메뉴를 못 찾을 때 이름으로) |
| ``Ctrl+` `` | 터미널 열기/닫기 |

## 5. 함정 (2026-07-23 실제로 겪은 것)

- **모르는 팝업이 "Allow / 예" 를 물으면 일단 Skip / 취소.**
  JDK 21 을 설치하고 소스를 갈아엎으려던 자동 업그레이드 확장이 실제로 있었다(§6-5 참고 — 확장은 제거함).
- **커밋 전 3초 점검**
  1. 좌측 하단 브랜치가 **`main`** 인가 (`appmod/...` 면 중단)
  2. 변경 파일이 **진짜 프로젝트 소스**인가 (`.github/modernize`, `plan.md`, `progress.md` 면 커밋 금지)
  3. 변경 내용에 **내가 의도한 수정**이 실제로 있는가 (빈 줄만 추가된 것 아닌지)
- 이 프로젝트는 **Java 8 전용** — "Java 를 최신으로 업그레이드하라" 는 권유는 전부 무시.

## 6. 이클립스와 다른 점

**VS Code 는 폴더 = 프로젝트다.** 워크스페이스 개념이 없어서, 다른 프로젝트를 열려면
**File → Open Folder** 로 그 폴더를 열면 된다.
현재 이 프로젝트는 `<사용자경로>\git\konet\konet_vsweb` 폴더를 연 상태다.

설정 저장 위치도 다르다.

| | 이클립스 | VS Code |
|---|---|---|
| 서버 등록 | 워크스페이스(프로젝트 밖) | `C:\Users\<사용자>\.rsp\...` (PC 로컬) |
| 빌드·Task 설정 | 프로젝트별 설정 | 프로젝트 안 **`.vscode\`** → **git 으로 공유됨** |

`.vscode` 가 git 에 함께 올라가므로 **절대경로는 모든 PC 에서 같아야 한다** →
그래서 도구 경로를 `C:\egv` 로 통일했다(§0). 다른 드라이브를 쓰는 PC 는 정션 한 줄로 맞춘다.

```
mklink /J C:\egv D:\egv
```
