## 1. 상품선택 팝업 — 다중선택 담기 (매입·판매 공통)

- 팝업 맨 앞 **✔칸**: 체크하면 순번(1,2,3…)이 찍히고 [확인 — 선택 담기]로 그 순서대로 명세에 담김.
- 줄 클릭 = 종전대로 한 건 즉시 담기. 이미 명세에 있는 상품은 건너뛰고 알림.
- **BOX수량 기본 1**: 다중선택뿐 아니라 한 건 담기(팝업 클릭·🔖 매칭코드 클릭·상품칸 인라인 검색)도
  수량이 빈 줄이면 BOX 1 (판매는 합계=EA 규칙이라 EA도 1). 수량 있는 줄(상품 바꾸기)은 안 건드림.
- 판매 팝업의 **🔖 매칭코드 줄도 ✔ 체크 가능** — 담기면 그 거래처 코드·품명으로.

## 2. 일괄등록 (매입·판매 동일 — puBatch* / saBatch*)

헤더의 [일괄등록] 버튼(창고 옆)으로 여는 대형 팝업. 거래처는 선택된 채 **일자만 바꿔가며** 여러 전표를 만든다.

### 레이아웃 (확정)
- **좌 = 담을 내용(58%, 높이 60vh)** / **우 = 목록 탭(42%)** 2단.
- 머리줄: `일괄등록 — 거래처 [판매/매입일자▾] ⚠일자힌트 [전체 초기화] ──── [💾 일괄저장(우측, ✕에서 112px 왼쪽)] ✕`
  — 글자·버튼 높이 30px 한 선상 정렬. 하단 푸터는 `담을 내용 N건 + [닫기]`만.
- 우측 탭: **[상품코드]**(코드순·장부식 이웃검색, 판매는 매칭코드로도 검색 + 🔖 줄 체크 가능)
  / **[최근 매입내역·판매내역]**(원장에서 최근 15일치, 일자 머리줄에 대표일자+**전표번호**, 일자별 전체선택.
  세부 줄에 일자 칸 없음. **판매는 직접판매(판매전표 STRX)만** — 정산서 제외).
- 우측 목록 상품명 210px 말줄임(전체는 툴팁).

### 담을 내용(좌측) 동작 (확정)
- **체크하는 순간의 일자(dt)가 그 줄의 등록일자** — 일자를 바꿔 체크하면 📅 일자 그룹으로 나뉜다.
  일자를 바꾸면 우측 체크 표시는 새 일자 기준으로 초기화(먼저 담은 건 좌측에 유지).
- 📅 그룹 머리줄: `일자 전표 — N건 — 이 일자로 저장됩니다` + 그룹째 삭제 ✖. **순번은 일자마다 1부터**.
- 각 줄: **BOX·EA·단가 입력칸**(본 명세와 동일 — 단가 소수점·콤마 허용, 수정 시 금액 재계산.
  판매는 BOX 치면 EA 따라옴). 수정 단가는 저장 시 최근단가로 안 덮음.
- **순서(▲▼) 칸은 순번 다음, 상품코드 앞** — 같은 일자 안에서만 이동. ✖ 빼기는 맨 뒤.
- [전체 초기화] = 확인창 후 모두 비움. 합계줄 `■ 합계 N건 · 전표 D장`.

### 일괄저장 (확정)
- **일자 그룹마다 전표 한 장씩 자동 발번·저장**(nextNo를 일자별로 새로 받음). 같은 일괄저장 안의
  같은 일자 체크분은 한 전표로 묶임.
- 확인창: `총 N건을 일자별 전표 D장으로 바로 저장할까요? + 일자별 건수 + ⚠ 기존 전표 있음(별도 전표로 추가)`.
  일자를 바꾸는 즉시 머리줄에도 `⚠ 이 일자에 전표 N건 있음` 힌트.
- **저장할 때마다 별도 전표**(기존 전표에 합치지 않음 — [같은 일자 전표에 합치기] 옵션은 구현했다가
  **사용자 요청으로 제거**. 재요청 시 git 이력 참조).
- 완료 알림에 발번 내역: `일자별 전표 D장, 총 N건 저장 / 2026-08-06 · 전표 0003 (2건)…`
- **저장 후 팝업 유지** — 담을 내용만 비우고 최근내역·힌트·하단목록·잔고 갱신. 명세 그리드는 안 건드림.
- [명세에 담기] 버튼은 제거(사용자 확정 — 일괄저장 하나로).

### 상품코드 표기 (확정 — 명세 그리드와 동일)
- **주코드 위 크게, 매칭코드는 아래 작게** `🔖 1000800225`(파란색 #274b8f 11px).
  일괄등록 담을 내용·최근 판매내역·명세 그리드 전부 동일.

## 3. 매칭코드 판매 기록 — TBL_SALES_TRX_DTL.EXT_CD 신설 (적용 완료)

- **문제**: 주코드/매칭코드 어느 쪽으로 판매했는지 DB에 없어 품명 추정으로 표시 → 화면 간 불일치·오판.
- **해결**: `ALTER TABLE TBL_SALES_TRX_DTL ADD EXT_CD NVARCHAR(50) NULL`
  ([docs/sql/sales_trx_dtl_extcd_alter.sql](sql/sales_trx_dtl_extcd_alter.sql), **운영DB 적용 완료**).
- SalesTrxDtlDTO.extCd 추가, User_SQL.xml: insertSalesTrxDtl에 EXT_CD 기록,
  selectSalesTrxDtl·selectCustDayDetail(STRX 분기)에 extCd 반환. **mvn compile 완료**.
- JSP는 저장된 EXT_CD로만 🔖 표시(품명 추정 폐기). **칼럼 신설 이전의 옛 전표는 표시 없음(정확).**
- ★순서 함정: 칼럼 없이 compile만 하면 판매 저장이 통째로 실패한다 — DDL 먼저.

  택배 발송 엑셀 생성(원양식 `D:\코네트\택배관련\테스트 자료.xlsx`).
