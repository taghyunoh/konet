## 카톡 공유 — 어떻게 되나
1. 저장하면 발주서마다 **공유 토큰**(24자)이 생긴다 → 공개 주소 `https://…/konet/pub/po.do?t=토큰`
2. 공개 주소는 **로그인 없이** 그 발주서 하나만 보여 준다(인쇄 양식과 같은 화면, 🖨 인쇄 가능). 토큰이 틀리면 「찾을 수 없습니다」만.
3. 💬 **카톡 공유** = 카카오 JavaScript SDK 「공유하기」 — 홀세일닥터 카드처럼 제목(발주서 — 거래처) · 설명(일자·품목·합계) · [웹페이지로 보기] 단추가 뜨고, 카톡에서 받는 사람을 고른다.
   - 키 = `src/main/resources/kakao.properties` 의 `kakao.js.key` (sejong_app 의 Kakao Developers 앱 JavaScript 키를 그대로 넣었다)
   - ⚠ **Kakao Developers ▸ 그 앱 ▸ 플랫폼 ▸ Web 에 이 사이트 도메인(allcare24.kr, 로컬 테스트면 localhost:9071)을 등록**해야 카드가 보내진다. 등록이 안 되어 있으면 SDK 가 거부한다.
   - `share.base.url` 을 채우면 카드가 여는 주소의 앞부분을 고정한다(프록시 뒤에서 host 가 다르게 잡힐 때).
4. 🔗 **링크 복사** = 공개 주소를 클립보드로 — 카카오 앱 설정 전에도 바로 쓸 수 있다. 카톡에 붙여 넣으면 og: 태그로 제목·합계 미리보기가 뜬다.
5. 공유하면 `SHARE_CNT`·`LAST_SHARE_DTTM` 이 늘고 목록에 💬 n 으로 보인다.

## 매입전환 (2026-09-03 「언제 들어왔는지 매입일자를 지정해서」)
- 발주서 화면 📦 **매입전환** → 창에서 **매입일자(실제 입고일)** · 창고 · 지급구분을 고르고 [매입전표 만들기]
- 서버 `/mangr/poToPurchase.do` 가 발주 머리·줄을 그대로 매입전표(`TBL_PURCHASE_MST/DTL`)로 만든다 — **매입 등록과 같은 저장 경로**(`savePurchase`)라 재고 입고(원장 I행)·단가 이력도 함께 생기고, 서브코드·거래중지 관문도 똑같이 건다. 전표 비고에 「발주서 yyyymmdd-0001 전환」이 남는다.
- 발주서에는 만들어진 전표(`PURCH_SEQ`)가 기억되어 목록 「매입전환」 열에 ✔ 일자-번호, 상태줄에 📦 매입전표 번호가 보인다. 다시 전환하면 매입이 두 번 잡히므로 경고 뒤 한 번 더 묻는다(전표를 지우면 표시가 사라지고 다시 전환 가능).
- 수량·단가·금액은 발주서 값 그대로. 실제 입고가 다르면 매입 등록 화면에서 그 전표를 고쳐 쓴다.
