## 0. 지금 「순마진」의 정체 (코드 실측)

| 화면 | 순마진 식 | 근거 |
|---|---|---|
| 매출마감 · 마감현황 KPI「순마진(매출-매입)」 · 마감 이력 표 · 대시보드 📊마진 3행 | **매출 − 매출원가**(나간 수량 × 매입단가) | `logistics_demo2.jsp:1305·1443·1584·3626`, `TBL_CLOSING_MST(SALES_AMT·COGS_AMT·MARGIN_AMT·PURCHASE_AMT·STOCK_AMT)` |

⇒ 이름은 순마진인데 **매출총이익**이다. 운임·수수료·인건비 같은 비용을 담는 표·칸은 **0개**(`수수료|판관비|경비|물류비` 전 소스 0건).
유일한 비용 흔적 = 사업장 표의 **택배 운임 `TBL_BIZI_MST.PARCEL_FEE`**(미설정이면 4500 하드코딩, `parcelOut.jsp:313`) — 택배 출력 종이에 찍는 용도뿐이고 어디에도 합산되지 않는다.

## 1. 무엇을 비용으로 볼 것인가 — 후보 4가지 ← 결정 ①

| | 비용 | 자료가 어디에 있나 | 넣는 방법 |
|---|---|---|---|
| **A** | **직송 택배 운임** | 택배출고관리의 직송 출고 건(`TBL_SHIPOUT_MST ZONE/DLV_GB='직송'`) × 사업장 운임(`PARCEL_FEE`) | **자동** — 이미 있는 자료로 계산된다. 사람이 안 넣는다 |
| **B** | 출고장(삼성웰스토리 센터) 물류비·수수료 | 정산서 엑셀에 공제란이 있는지 **코드로는 모른다**(업로드 매핑에 수수료 열 없음) | 있으면 정산서 업로드 때 같이 읽기 · 없으면 월 수기 |
| **C** | 월 고정비 — 인건비·차량·임차·통신·보험… | 프로그램 밖(회계) | **월 1회 수기 입력**, 전월 복사 |
| **D** | 매입 부대비 — 입고 운임·포장 | 없음 | 매입전표에 얹기 → 매입단가에 녹는다(관행) |

**추천 = A + C** 로 1단계. A 는 근거가 화면에 있어 「이 달 택배 몇 건 × 얼마」로 검증되고, C 는 한 줄이라도 넣어야 순마진이 «총이익»에서 «이익»으로 내려온다.
B 는 정산서 원본을 한 장 보고 정한다(공제란이 있으면 그때 열 하나 추가). D 는 뺀다 — 단가에 넣는 편이 품목별 마진과도 맞는다.

## 2. 어디에 담나 ← 결정 ②

| 안 | 내용 | 판정 |
|---|---|---|
| **1 (추천)** | **새 표 2개** — 비용 항목 마스터 + 비용 전표. 마감 확정 때 합계를 `TBL_CLOSING_MST` 에 굳힌다(재고·수금 마감과 같은 «스냅샷» 사고) | 이력이 남고, 거래처 잔액과 섞이지 않는다 |
| 2 | 지급등록(`TBL_SETTLE_TRX` PAY)에 「비용」 구분을 더한다 | ⛔ 채권·채무·일계장이 그 표를 거래처 잔액으로 읽는다 — 비용이 지급할금액을 갉아먹어 잔액이 틀어진다 |
| 3 | 회사 설정(`TBL_COMP_SET.SET_JSON`)에 월 고정비 | ⛔ 달마다 값이 다른데 이력이 안 남는다 |

### 표 (안 1)
```sql
-- 비용 항목 마스터 — 「무엇을 비용으로 세는가」의 목록. 화면에서 추가·정렬·사용 끄기
TBL_EXPENSE_ITEM  ( COMP_CD, ITEM_CD PK, ITEM_NM, ITEM_GB('FIX' 고정/'VAR' 변동), AUTO_SRC(NULL/'PARCEL'), SORT_ORD, USE_YN, REG/UPD… )
  씨앗 : PARCEL 직송 택배 운임(VAR, AUTO_SRC='PARCEL') · LABOR 인건비(FIX) · VEHICLE 차량(FIX) · RENT 임차(FIX) · ETC 기타(VAR)

-- 비용 전표 — 달 × 항목 한 줄(수기). 자동 운임은 전표를 만들지 않고 집계 때 센다(§3)
TBL_EXPENSE_TRX   ( EXP_SEQ IDENTITY PK, COMP_CD, EXP_YM 'YYYYMM', ITEM_CD, AMT DECIMAL(15,0), VENDOR_CD NULL, REMARK, ACTION_YN, REG/UPD… ,
                    UNIQUE(COMP_CD, EXP_YM, ITEM_CD) )

-- 마감 스냅샷에 2칸
ALTER TABLE TBL_CLOSING_MST ADD EXPENSE_AMT DECIMAL(15,0) NULL,   -- 그 달 비용 합계(자동 운임 + 수기)
                                NET_MARGIN_AMT DECIMAL(15,0) NULL  -- 순마진 = MARGIN_AMT − EXPENSE_AMT
```
`TBL_CLOSING_MST` 의 `MARGIN_AMT` 는 그대로 «매출총이익»으로 두고 이름만 화면에서 바꾼다(옛 마감 이력이 안 깨진다).

## 3. 자동 운임 — 계산 규칙
- 건 = `TBL_SHIPOUT_MST` 그 달 직송 출고 **사업장 × 출고일자**(택배출고관리가 한 장으로 묶는 단위와 같게 — 택배 한 상자는 한 건이지 품목 줄 수가 아니다).
- 단가 = 사업장 `PARCEL_FEE`, 없으면 **회사 설정 기본 운임**(지금 4500 하드코딩 → `comp-set` `parcelFeeDef` 로 올린다). 미등록 사업장(`bizYn='N'`)도 기본 운임으로 센다.
- 비용 등록 화면에 「직송 택배 N건 × 평균 ○원 = △원」 읽기 전용 줄 + [택배출고관리 그 달 보기]. 수기로 고칠 수 있게 할지는 결정 ⑤.
- ⚠택배사 요율표(무게·도서산간)로 셀 자료는 없다 — 사업장 운임이 곧 단가다. 요율표를 쓰려면 자료부터 받아야 한다.

## 5. 결정할 것 5
1. **비용 범주** — A+C(추천) / A만 / A+B+C(정산서 공제란 확인 뒤).
2. **담는 곳** — 새 표 2개 + 마감 스냅샷 2칸(추천) / 지급등록 구분(비추) / 회사 설정(비추).
3. **이름** — 지금 「순마진」을 **「매출총이익」**으로 바꾸고 순마진 = 총이익 − 비용(추천) / 옛 이름은 그대로 두고 「순이익」을 새로.
4. **부가세** — 비용은 **실제 나간 돈(세포함)**(추천, 매출·원가도 세포함 기준이라 같은 잣대) / 공급가.
5. **자동 운임 수정 허용** — 읽기 전용(추천, 근거가 택배 화면에 있으니 거기서 고친다) / 금액을 덮어쓸 수 있게.

먼저 확인해 주면 좋은 것 2 : ①정산서 엑셀에 **수수료·공제 열이 있는지**(B 를 가른다) ②월 고정비를 **몇 항목이나** 넣을 생각인지(항목 씨앗을 그대로 쓸지).
